# NOVIGO V2 — Documentation

Transformation de NOVIGO en Super App de niveau international. La V2 **conserve
l'architecture V1** et n'altère pas l'existant : elle ajoute un socle réutilisable,
de nouveaux modules, une couche d'API mock asynchrone, des intégrations (seams) et des tests.

## 1. Socle V2 réutilisable
- **Animations** (`src/lib/motion.ts`) : variants `fadeUp/fadeIn/scaleIn/slideInRight`, `staggerContainer/Item`, `pageVariants`, transitions `spring/springSoft/easeOut`, `tap/hoverLift`.
- **Reveal** (`src/components/ui/reveal.tsx`) : `<Reveal>`, `<RevealGroup>`, `<RevealItem>` — apparition au scroll.
- **Skeletons de domaine** (`src/components/ui/skeletons.tsx`) : `StoreCard/ProductCard/ListRow/Rail/Grid/KpiRow/Table/Chart` Skeleton.
- **États async** (`src/components/ui/async-state.tsx`) : `<AsyncState>` et `<QueryState>` (pont TanStack Query) — loading / erreur / vide uniformisés.
- **Images** (`src/components/ui/smart-image.tsx`) : `<SmartImage>` (skeleton + fondu).
- **Hooks** (`src/hooks/index.ts`) : `useDebounce, useMediaQuery, useIsDesktop, useCopy, useReducedMotion, useScrolled, useCountUp`.
- **Loading routes** : chaque route dispose d'un `loading.tsx` (skeleton structurel) → performance perçue optimale.

## 3. API Mock (`src/mock/api.ts`)
Toutes les méthodes renvoient des **Promesses** (latence simulée) → états de chargement
authentiques via TanStack Query. Signatures identiques à un vrai REST : remplacer le
corps par `fetch` suffit. Les générateurs déterministes vivent dans `src/mock/modules.ts`.

## 4. Intégrations (seams — `src/services/`)
Implémentations **mock mais fonctionnelles**, API publiques stables pour brancher le réel :
- **Temps réel** `realtime.ts` — canal type WebSocket (`createChannel`), émet `driver_location`/`order_status`. → Socket.IO / Firebase RTDB.
- **Paiements** `payments.ts` — `charge({provider, amount})` unifié : **Stripe** (carte), **Wave**, **Orange Money**, **Moov Money**, espèces, portefeuille.
- **Carte** `map-view.tsx` — `<MapView markers progress>` (placeholder SVG). → Google Maps / Mapbox.
- **Push** `push.ts` — `registerPush()`, `onPushMessage()`. → Firebase Cloud Messaging.

## 5. Données, seeders, factories
- **Seeder** : `npm run seed` → instantané JSON déterministe (`src/data/generated/`).
- **Factories** (`src/mock/factories.ts`) : `makeProduct/makeOrder/makeReview/makeAddress/makeWalletTx`, `makeMany` — surcharges partielles pour tests/démo.
- Volumétrie cible V1 conservée (voir `DATASET_TARGETS`) : 1450 commerces, 43k+ produits, etc.

## 6. Tests
- **Vitest** : `npm run test`. Couvre `src/lib/utils` et le socle données/modules/`api` (déterminisme, volumétrie, contrats async).

## 7. Qualité — commandes de vérification
```bash
npm run typecheck   # 0 erreur TS
npm run test        # tests verts
npm run build       # build de production
npm run dev         # http://localhost:5173
```
